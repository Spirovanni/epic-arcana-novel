# Location Images

This directory contains images for the mystical locations of Laurasia in the Epic Arcana series.

## Image Requirements

- **Aspect Ratio**: 3:2 (width:height)
- **Recommended Resolution**: 1200x800px or higher
- **Format**: JPG, PNG, or WebP
- **File Size**: Optimized for web (typically < 500KB)
