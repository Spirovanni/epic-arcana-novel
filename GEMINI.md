# Gemini Context: epic-arcana-novel

This file provides context and guidelines for Gemini when working on the `epic-arcana-novel` project.

## Project Overview

`epic-arcana-novel` is a web application for an interactive novel. It uses a Next.js frontend and a PostgreSQL database with Drizzle ORM to manage the story, characters, and timelines. The application will display and manage the lore of the "Epic Arcana Novel".

## Tech Stack

-   **Framework:** Next.js
-   **Language:** TypeScript
-   **Database:** PostgreSQL
-   **ORM:** Drizzle ORM
-   **Styling:** Tailwind CSS
-   **Package Manager:** yarn

## File Structure

The file structure for this project is defined in `STRUCTURE.md`. Please refer to this file when making decisions about file organization.

## Development Guidelines

-   **Code Style:** Follow the existing code style and conventions found in the project. Use Prettier and ESLint for formatting and linting.
-   **Package Management:** Use `yarn` for all package management tasks (e.g., `yarn add`, `yarn remove`, `yarn install`). Do not use `npm` or `pnpm`.
-   **Database Migrations:** Use Drizzle Kit for generating and managing database migrations. Migrations are located in the `drizzle/` directory.
-   **Commits:** Follow conventional commit standards for commit messages (e.g., `feat:`, `fix:`, `docs:`, `chore:`).

## Key Directories

-   `src/app`: Main application pages and API routes.
-   `src/components`: Reusable React components.
-   `src/lib`: Core library functions, including database connection (`db.ts`) and schema (`schema.ts`).
-   `lore/`: Contains all the JSON files for the novel's lore, characters, and story.
-   `drizzle/`: Contains the SQL migration files generated by Drizzle Kit.
-   `scripts/`: Node.js scripts for various tasks, like seeding the database.
