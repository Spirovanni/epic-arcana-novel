# Gemini Context: drizzle

This directory contains the database migration files generated by Drizzle Kit.

## Guidelines

-   **Do Not Edit Manually:** Do not edit the files in this directory manually. They are generated automatically by Drizzle Kit.
-   **Creating Migrations:** To create a new migration, run `yarn drizzle-kit generate:pg`. This will compare the current state of the database schema (`src/lib/schema.ts`) with the last migration and generate a new migration file.
-   **Applying Migrations:** To apply migrations to the database, run `yarn drizzle-kit migrate:pg`.
