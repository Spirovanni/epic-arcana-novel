/**
 * PROJECT OVERVIEW:
 * Epic Arcana is an AI-assisted, story-driven authoring platform for speculative fiction and historical fantasy built around nonlinear timelines, tarot-based Trionfi systems, and character evolution arcs.
 * It is also a tiered membership platform empowering community participation in story development, voting rights, co-authoring privileges, and lore creation influence.
 */

/**
 * CORE OBJECTIVES:
 * - Deliver a modular creative engine with deep AI support
 * - Render a custom fantasy map (from user-supplied artwork) using Mapbox/Leaflet
 * - Provide timeline-aware scene editing and character arc tracking
 * - Support lore-based interactivity and crowd-based narrative shaping
 */

// 🗺 MAP INTEGRATION INSTRUCTIONS
### Leaflet.js Approach (for PNG map):
- Place your custom image (e.g. `public/maps/laurasia.png`)
- Use CRS.Simple projection:
```tsx
<MapContainer center={[500, 750]} zoom={2} crs={L.CRS.Simple}>
  <ImageOverlay url="/maps/laurasia.png" bounds={[[0, 0], [1000, 1500]]} />
  {locations.map(loc => <Marker position={loc.coords}><Popup>{loc.name}</Popup></Marker>)}
</MapContainer>
```

### Mapbox Tiles Approach:
- Upload your map as a tileset via Mapbox Studio
- Use Mapbox GL JS with custom style URL
- Pull lore pin data from Supabase `locations` table
